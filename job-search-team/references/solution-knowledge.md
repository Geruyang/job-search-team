# 私有问题文件与本地解决方案知识库

## 授权与创建

首次建议用户授权本地经验留存，并记录位置、保留要求与授权依据；已有授权不重复询问。拒绝不阻止技能使用，也不得换名字创建替代问题库。任务必需的提交回执和防重记录按独立数据授权处理。未启用经验库时，跨会话历史取决于模型可用上下文及用户另行提供资料，不保证完整记忆。

获准后，从完整技能目录运行：

```sh
node "<技能目录>/scripts/init-knowledge.mjs" --workspace "<已存在的私有工作区>" --enable
```

已有知识库另在工作区内部时追加 `--knowledge-dir "<工作区内相对目录>"`。目录不得越出工作区，不穿越符号链接，不复制作者或其他用户的私有案例。

生成或保留的最小结构：

- `<工作区>/问题及解决.md`：统一症状入口、可复用结论、未决边界和更新记录；首次为无私人案例的空模板。
- `<知识库>/README.md`：案例关键词索引、当前入口和未解决项。
- `<知识库>/incidents.jsonl`：逐案证据和状态更新；初始为空，不假造事件。
- `<知识库>/人工干预记录.md`：本人发送、电话作答、窗口恢复、权限操作和人工接管。
- `<工作区>/会话接续.md`：新会话应先读的文件及状态核对步骤。
- `<工作区>/AGENTS.md`：追加本工具维护的运行协议，不覆盖原项目规则。支持该文件的宿主启动时读取；其他宿主应显式加载。
- `<工作区>/.gitignore`：排除上述私人运行文件；手工打包仍须核实际清单。

工具只创建缺失文件，已有问题、案例及人工记录不改写；重复运行保持同一受管协议单份。若已有受管协议与本次路径不一致，停止并先核路径。它不访问网站、不发送消息、不启动服务或定时任务，也不替代Agent的维护责任。

## 运行协议：先查、处理、及时回写

1. **启动与恢复。** 启动、交接、恢复及上下文压缩后，先核任务状态、最新指令和授权，再读问题文件、知识库索引和相关未决项。旧active记录不自动恢复任务。
2. **问题发生。** 错误、异常结果、工具拒绝、用户纠正或人工介入出现时，在再次尝试前检索症状、报错、平台、版本，读取命中结论及必要原证据。没有案例就先登记现象与unknown，不能因为未解决而不记录。
3. **采用办法。** 对照当前版本、页面、权限、任务状态及在途命令判断旧办法是否适用。经验不能授权绕过验证、穿透遮挡、换通道重发被拒内容或重放unknown。
4. **当次更新。** 每次发现、尝试结果、解决、失败、纠正或接管后，当次更新问题文件的当前结论与未决边界，同步知识库索引以及有新增细节的案例/人工记录，在下一次相关业务动作前完成。原证据不重复抄写，保留本地引用；回合结束只补归并和下一步。
5. **去重与过时。** 同类沿用稳定ID，记录变化、失败及修正依据；被新规则覆盖标superseded并链新结论，不删旧事实。恢复后出现回执不自动证明恢复动作触发发送。
6. **协作。** 指定一名问题文件/索引维护者，其余角色提交带证据更新，避免覆盖；不强行启动额外Agent。主文件暂不可写时保存经授权的本地待合并记录并说明，不宣称已更新。

## 记录字段与证据

每案至少有：`id / occurred_at或unknown / platform / symptom / environment_version / attempted_steps / outcome / evidence_refs / human_intervention / reusable_method / limits / status / updated_at`。用户纠正另记生效范围、依据和被覆盖条款；不继承其他用户偏好。

人工字段说明谁做了什么、证据、是否解决及是否接管。未发生记none，无法确认记unknown，不把本人动作计作Agent新增。区分页面实测、代码检查、模拟测试、用户确认、推断及未验证，状态可用 `verified / user_confirmed / partial / unresolved / superseded` 并注明范围。ACK、输入清空、PNG生成、源码修改和测试通过都不能独立证明业务成功。

## 私密性与迁移

问题文件和实际知识库留在私有工作区，不进入公开技能、仓库、发布ZIP或日志示例。只保存必要摘要和证据指针，不复制完整简历、聊天或联系方式；Cookie、配对密钥、身份证号不入库。通用包只含空模板、机制和匿名方法，不携带作者真实案例、公司状态、账号、权限或投递游标。

跨会话见[接续说明](session-handoff.md)。跨设备私有资料由用户另行选择提供，登录、配对密钥与标签ID不随公开包迁移。公开发布同时核白名单、实际目录和ZIP内部文件，`.gitignore`不保护手工压缩。
