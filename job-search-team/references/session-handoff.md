# 导入与跨会话接续

## 新用户或空白工作区

1. 完整解压并导入技能目录，保留 `SKILL.md / references / scripts / assets`，不能只传入口文件。
2. 读取入口并先完成用户自己的资料、评分、否决、权限及停止条件；没有这类资料不能直接替用户投递。纯云端文件对话不等于本机工具连接。
3. 经验留存获准后运行 `scripts/init-knowledge.mjs --workspace "<私有工作区>" --enable`。工具创建空问题文件、知识库与项目规则；拒绝留存则跳过，其他技能功能仍可用。
4. 按 `references/setup.md` 部署助手、用户登录并验收。运行脚本仅需Node内置模块，真实浏览器安装和登录仍按环境权限执行。

## 同一用户的新会话

让新会话访问完整技能目录和原私有工作区，读取生成的 `会话接续.md`、项目规则、`问题及解决.md`、知识库索引、当前用户配置及最新回执。先核任务是否暂停、未知提交和人工接管，再决定可执行范围；导入文件本身不表示恢复任务或新增外发授权。

支持 `AGENTS.md` 的宿主会按其约定发现项目规则；其他宿主显式加载该文件，或把其中运行协议作为任务指令。不能承诺任意文件上传环境自动执行本机脚本，也不能称Markdown协议是后台自动更新服务。

## 哪些文件可以分享

公开可分享：完整通用技能ZIP、助手源码、空模板、匿名说明、安装与测试脚本。

只在用户授权的私有环境接续：用户简历、当前policy/授权、真实回执、公司状态、意向游标、`问题及解决.md`及本地知识库。仅引用这些文件的路径并不包含它们；换设备须由用户另行选择提供并核路径，不随公开技能混装。

不从旧设备迁移登录凭据、Cookie、配对密钥或标签ID；在新环境重新登录配对。主工作区问题文件与案例以同一维护者归并，避免多个会话各自写不一致副本。
