# 初始化功能验收表

在用户提供资料、策略与权限，完成助手部署和平台登录后执行。每项记 `pass / failed / not_tested / blocked / not_applicable`、时间、环境版本、模拟或实机、私有证据位置。报告不复制密码、配对令牌或完整个人内容。以下是验收要求，不是已通过的承诺。

| 功能 | 本机模拟/离线测试 | 真实环境验收与边界 |
|---|---|---|
| 资料与权重 | 真实输入结构、权重合计、未知分与区间、匿名主体规则 | 简历版本/语言与用户确认一致；示例不作为真实评估 |
| 私有问题/知识库（可选） | 授权后初始化、拒绝不写入、原文件保留、重复运行、越界拒绝及独立CLI | 核真实问题文件和知识库路径；启动先读，遇错先查，每次结果/纠正当次更新；纯文档协议不冒称后台服务 |
| 初次搭建与复用 | 空工作区、新配对、重启复用、不覆盖已有文件 | CLI健康、connected、安装加载目录及版本正确 |
| 连接与权限 | 配对校验、停止连接、撤回权限、错误代际/过期拒绝 | 核对所选平台账号/标签；取消选中后重新读取应被阻止，再在授权内恢复 |
| 页面与导航 | URL/document/ref守卫、仅允许已观察链接 | 读取JD、搜索列表、历史；导航只在当前任务允许时，不为测试刷新招聘页 |
| 填写/点击/选择/滚动 | 模拟DOM控件与遮挡处理 | 采用实际任务中的必要操作核验，不测试点击“发送/投递”或修改线上简历 |
| 截图与切页 | 超时、页面变更丢弃、窗口状态、新鲜度提示 | 两站各保存一张到私有目录，并在允许时A→B→A核对；用户不许切页则不执行自动切页截图 |
| 背景/最小化 | 模拟最小化和状态变化 | 若用户要求且允许，另测；API返回成功还需对照当下内容。锁屏/长期运行未测就标未测 |
| 图像识别 | 插件只供图，无内置OCR模型 | 宿主可看图时辨认会话、入口和回执；不可看图则声明能力缺失，按授权文字核验 |
| 聊天 | 模拟填充、单击、失败回执 | 只在真实获准会话中测试默认问候、介绍和后缀；没有实际任务则未测 |
| 附件/同意请求 | 模拟单次动作和回执处理 | 必须有真实收件人与附件授权；核对请求/附件/正式投递，BOSS迟滞先切回目标页 |
| 手机号/微信/拒绝 | 模拟操作路径 | 只在用户实际授权需要时使用平台按钮；身份证号默认禁发，不做测试外发 |
| 异常恢复与去重 | 断连、命令过期、旧引用、重复认领 | 未知提交只读对账；不为了测试断开真实在途动作、不重放、不跨渠道绕过拒绝 |
| 隐私与导出 | 发布白名单、敏感文本扫描、压缩包逐项检查 | 公开包不含运行目录、个人简历、聊天、截图、用户配置、联系方式、令牌 |

## 自动测试

从技能目录运行：

```sh
node --test scripts/test-score.mjs scripts/test-bootstrap.mjs scripts/test-attitude-review.mjs scripts/test-knowledge.mjs assets/browser-bridge/tests/*.test.mjs
```

测试使用临时服务及模拟浏览器，不需要用户账号，不向招聘平台发送消息。需要本机回环与子进程权限。通过后仍须新环境只读验收；真实发送仅在实际授权任务中补验。测试结果见发布包 `VALIDATION.md`，不把历史实测当作本次实测。

## 私有报告格式

记录环境、策略/授权版本、安装/扩展/服务版本、每项结论及证据。对失败项给出实际错误、尝试过的恢复和下一步；区分已解决、可降级、仍未解决。说明哪些能力可以进入任务、哪些需要暂停，避免无限反复要求用户重载。
