# 简历网页助手 V2.0

在用户本机连接 Chrome/兼容 Chromium 浏览器中的 BOSS 和猎聘页面。包括扩展、Node.js桥接服务和命令行；不依赖专有智能体宿主或模型，不使用 CDP/debugger。

## 独立安装

需要Node.js 22+。将完整助手目录保存在可写位置，先确认用户的任务、账号和操作权限，再在该目录运行 `node server.mjs`（保持进程运行）。Chrome扩展管理页选择“加载已解压的扩展程序”，加载 `extension/`；点击扩展图标，导入本机新生成的 `.local/extension-pairing.json`，连接后让用户登录所需平台并核对已选标签。配对文件不要发送给他人。Windows也可用 `start.ps1` 在后台启动。

控制面板会发现并选中招聘页，技术读写权限不代表对外发送授权；撤销无关标签并保持面板开启。用 `node cli.mjs health`、`status`、`tabs`、`snapshot <真实标签ID>` 核验，再开展获准任务。

截图：`node cli.mjs screenshot <真实标签ID> <新的本地图片路径.jpg>`。命令会切换目标为活动标签，需事先获准；不主动刷新。图像含私密内容，不公开上传。查看/识别图像依赖使用者的图像工具，助手不内置OCR或视觉模型。

## 权限和限制

`<all_urls>` 用于 Chrome 持续截图授权，浏览器会提示较广的网站访问权限；用户应知情并接受才安装。代码业务范围仍仅限明确列出的招聘域名和用户选中的标签；不读取Cookie/历史，不提供任意网站控制。用户不接受截图授权则停止相应功能，不绕过浏览器限制。更改manifest后需重新加载扩展并接受权限，重开面板不等效。

截图10秒超时有诊断及清理。最小化/状态未知的截图标记可能陈旧，不能单凭成功返回确认发送；正常窗口也需核对当前会话。`activate` 请求现有标签与窗口前台，须有前台授权。BOSS提交后迟滞优先切回目标标签查回执，不重复点击发送。猎聘会话卡与正式投递记录分别核对。

`visual-capture.mjs` / `visual-guard.mjs` 是实验性提供方接口与目标检查，不自带独立截图后端；不要将其称为隐藏内嵌页截图实现。多系统代码可移植性不代表每个系统已实机测试。

## 本机验证和隐私

`node --test tests/*.test.mjs` 使用模拟浏览器与临时服务，不进行真实外发。真实登录、页面和截图在当前设备另行验收。全部状态/证据只放本地；`.local`、会话、配对、简历、截图和用户配置均不得进入公开包。插件按授权把简历或消息发送到招聘平台属于真实对外动作，不是本地测试。
